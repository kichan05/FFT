# 프로젝트 진행 방법
1. 간단한 이산 푸리에 변환(DFT) 알고리즘을 구현합니다.
2. 고속 푸리에 변환(FFT) 알고리즘을 학습하고 직접 구현합니다.
3. Kaggle에서 고앙이와 강아지 울음소리 데이터셋을 탐색해줍니다.
4. 소리 데이터의 시간에 따른 신호데이터를 학습시킨 분류 모델을 생성합니다.
5. FFT의 결과인 주파수의 세기를 학습한 분류 모델을 생성합니다.
6. 두 모델의 정확도를 각각 비교해줍니다.
